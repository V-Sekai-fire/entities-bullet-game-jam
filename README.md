# entities-bullet-game-jam

Branching-story scripts in `.ink` format and a storyboard, written for a game jam.

## What it is for

`bullet-train-jam.ink` is a dice-driven story set on a sleeper train, and `hover-sub-ocean.ink` is a journey that starts in a hovercar. The PDF is a storyboard for the train story's opening.

## Build and run

Open either script in an editor for the `.ink` narrative language to play it.
